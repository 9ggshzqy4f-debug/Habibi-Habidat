# Habibi Habidat by eishold

**Managed Housing as a Service** — owner-facing operating model + guest-facing hospitality brand.

## Product architecture
- Corporate / owner brand: **Habidat Managed by eishold**
- Guest-facing hospitality brand: **Habibi Habidat**
- Operating software layer: **Habidat OS**
- Pilot portfolio: Frankel-owned short-/mid-stay units in Vienna

## Compliance posture
Go-live per unit is gated by owner-provided proof of the applicable rights/permissions for the intended use. The platform does not represent that an apartment is legally eligible for short-term accommodation merely because it can be technically listed.
